# dsh-import-customs-check

> **Repositorio oficial. El único repositorio oficial de este paquete, mantenido por PerryLink. Apache-2.0.**

</div>

Compara campo por campo la factura, la lista de empaque, el conocimiento de embarque y la declaración de aduana de un envío de importación, y enumera los elementos faltantes de la declaración. Todo se ejecuta localmente, sin red ni carga de datos.
